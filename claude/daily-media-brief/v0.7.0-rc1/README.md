# v0.7.0-rc1｜二檔結構

## 這版改了什麼

**結構**：10 檔 52KB → **2 檔約 7KB**。執行只載 `SKILL.md` + `topic.yaml`。

**規則**：選新聞的判準（日期驗證、相關性評分、去重、摘要）**一字不改**，從 rc1 壓縮進來。

**改的是怎麼跑**：
- 每批 4–5 條平行搜，不再一條一條
- Ledger 壓縮成一行一則，含 G2–G6 證據
- 達標即停，不慣性跑滿三層
- 去重後才開原文，不對將被去掉的開
- 進度一行，不敘述階段
- 五份輸出合一
- G8 前加 R1/R2 自檢（不用工具）
- 日期用曆日，省掉取時間

**留著沒開的**：`topic.yaml > options.trust_se_date` 預設 false。品質穩了再開。

## 換主題

複製 `topic.yaml` → 改關鍵字、查詢、來源、相關性錬點 → 存回 `topic.yaml`。`SKILL.md` 不動。
主題庫在 `topics/`。

## 四階段驗證方法

| 階段 | 做什麼 | 量什麼 | 通過條件 |
|---|---|---|---|
| 0 | 用 rc1 跑一次 | tool call、則數、品質 | 對照組 |
| 1 | 用本版跑一次 | 同上 | 品質＝階段 0，tool call ↓ |
| 2 | 開 trust_se_date 再跑 | 同上 | 品質不降，驗證次數 ↓ |
| 3 | 換主題跑 | 能不能跑 | 跑得動 |

每階段把「執行行」到「統計行」貼回來，比對後才進下一階段。
