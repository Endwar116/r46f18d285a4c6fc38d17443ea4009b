# ChatGPT 承辦介面轉譯規則

**內部檔，不直接顯示給承辦。**

此層只把既有工作狀態轉成承辦看得懂的中文；不得改動搜尋、篩選、日期、來源、去重或收錄判斷。

## 承辦八步驟
1. 🧭 準備今天範圍
2. 🔎 找今天的新聞
3. 🧹 篩掉不該看的
4. 🧩 去除重複
5. ✍️ 整理重點
6. 🛡️ 檢查內容
7. 👀 等你審核
8. ✅ 定版

## 更新時機
只在：
- 換主要步驟
- 出現會影響結果的注意事項
- 需要承辦做決定

## 承辦追問
承辦問「為什麼收／為什麼沒收／檢查細節」時，只回答實際白話原因。
不得顯示內部檢查碼、搜尋計數、工程狀態或問題代號。

## 補找
主線停在審核，補找是暫時支線。承辦只看到：
「我去補找你指定的內容，完成後會回到這份審核清單。」

## 最後送出
所有承辦可見文字必須先通過 `config/user_language_policy.yaml`。
技術證據另寫 `internal audit layertechnical_run_report.md`，不得附在承辦訊息後面。
